# Chat

Home is your conversation with Auto. Type a message, add a photo or a file, and Auto answers in the same thread.

<!-- IMAGE: A thread with the user's grey box on the right, Auto's answer beside the sail, and the Thinking pill -->

## Reading the thread

* **"Auto is an AI"** is a small line at the top of every conversation. It scrolls away with the thread. When another agent answers, it names that agent.
* **Your messages** sit in a grey box on the right.
* **Auto's answers** sit in a box beside Auto's sail.
* **Thinking** shows in a small pill while Auto works on your answer.
* **What Auto did** lists what Auto did for this answer, each with Done, Not done or Skipped.
* **A line for each tool** shows while Auto works, with a spinner while the tool runs and a mark when it ends. VoiceOver reads how it went: Running, Done, Failed, Waiting for you, Skipped or Stopped.

Auto's answers are formatted: headings, lists, task boxes, code, tables and quotes. You can select and copy the words. When you tap a link to another site, the app asks first, for example "Open example.com?".

## Send a message

1. Type in **Message Auto** at the bottom.
2. Tap the round button to send.

Return starts a new line; only the button sends. While Auto answers, the button turns into **Stop**. Tap it to stop the answer, and the thread says "You stopped this reply." If the stop doesn't get through, the thread says "Auto couldn't be stopped. It is still working on this."

## Add photos and files

Tap **+** beside the message box. **Add to your message** offers:

| Choice | What it does |
| --- | --- |
| **Camera** | Take a photo |
| **Photo library** | Choose photos |
| **Files** | Choose a document |

* Up to 20 files in one message, and up to 50 MB each.
* Photos only from the camera and the library: no video.
* Before a photo is sent, the phone makes a fresh copy of it, without the location and camera details stored inside the photo.
* The app asks to use the camera the first time you tap **Camera**. The photo library and Files don't need your permission: the app only sees what you choose.

If a file can't go, the app says why under its name, for example "Files can be up to 50 MB." or "Auto can't take this kind of file."

## Cards in Auto's answers

Some answers carry a card for you to act on.

| Card | What you can do |
| --- | --- |
| **Mission · Suggested** | Auto suggests running the work as a Mission. **File it** or **No thanks**. A filed Mission shows "✓ Filed as a Mission" and **Open it in Studio**. |
| **Mission · Plan to approve** | **Approve & run** starts the Mission. **Reject** asks why, so Auto knows what to change. |
| **Action · Approval needed** | An agent wants to run a tool. It shows what the tool will run with. **Approve & run** or **Deny**. |
| **Withdraw request** | **Withdraw** or **Keep it**. |
| **Ticket** | A ticket Auto filed, for example "filed to Inbox". **Open on the board** opens it in the Command Centre. |

If someone already decided a card, the card says so, for example "This plan was already approved."

## When Auto can't answer

A failed answer shows as a quiet line in Auto's box, with **Try again** under it where trying again can help. **Try again** asks the same thing again.

| What you see | What to do |
| --- | --- |
| "Auto is rate-limited right now. Try again in a minute." | Wait a minute, then tap **Try again**. |
| "The model Auto uses isn't available right now. Try again later." | Try again later. |
| "Auto has reached a limit for now. Ask your workspace owner." | Ask your workspace owner. |
| "Auto has no AI provider key in this workspace. Ask your workspace owner." | Your workspace owner adds one in Studio. |
| "The reply was interrupted. Try again." | Tap **Try again**. |
| "Auto couldn't open" and a file name | Auto answered without that file. Send it again, or try another format. |

## Older chats

Open the menu and tap **Chats**. **Conversations** lists your chats, newest first, with **Load more** at the bottom. A chat that Auto started by itself is marked **Auto**. Tap **New chat** to start a fresh one. **New chat** is also in the menu.

## Talk to Auto about a ticket

From a ticket in the Command Centre, tap **Ask Auto about** and the ticket number. A new chat opens with "Discussing" and the ticket's title at the top. See [Command Centre](command-centre.md#talk-to-auto-about-a-ticket).

## Report this

**Report this** lets you flag one of Auto's messages: touch and hold the message. It asks what is wrong with it (Harmful or dangerous, Offensive or hateful, Wrong or misleading, Shares private information, Something else) and lets you add a short note. Your workspace owner sees the report.

## If you are a viewer

Viewers read the thread but can't send. The message box says "Read only", with "Ask your workspace owner for editor access to talk to Auto" under it.
